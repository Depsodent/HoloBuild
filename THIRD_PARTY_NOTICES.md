# Third-party notices

HoloBuild's original source has no open-source license grant yet (`UNLICENSED`); public visibility alone does not license it. Existing author attribution is retained. Third-party software retains its own licenses.

The locked runtime dependency inventory and included license/notice files are generated by `npm run prepare:licenses` at `public/third-party-notices/`, served at `/third-party-notices/index.json`. This includes transitive production packages, not just direct dependencies. Generated copies are excluded from Git and prepared during each build. Missing upstream notice files are reported with package SPDX metadata; review those entries before publishing.

Direct dependencies include React/React DOM, Three.js, React Three Fiber/Drei, Zustand, Zod, Lucide and MediaPipe Tasks Vision. Read their individual generated notices; no claim of a single common license is made.

MediaPipe Tasks Vision and the Hand Landmarker model are distributed under Apache-2.0. The full official license is retained at `licenses/mediapipe-LICENSE.txt` and copied into the public notices. The version-1 float16 model is fetched at build setup from Google's model repository, checksum-verified, and excluded from Git. Official model card: https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20%28Lite_Full%29%20with%20Fairness%20Oct%202021.pdf . Official source: https://github.com/google-ai-edge/mediapipe .

HoloBuild's wood/brick/concrete textures are generated procedurally by its source; no third-party photo/HDR pack is bundled. Test model fixtures are generated from primitive geometry. User-imported models remain browser-local; users must have permission to use assets they import or share in exported projects. Imports are not uploaded to Gemini. No user asset files are included in this repository.

The generated inventory records that declaration. Obtain its upstream notice before public distribution; no copyright owner or additional grant has been invented. Notice provenance for other recovered files is in `licenses/SOURCES.json`.
