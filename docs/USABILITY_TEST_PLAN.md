# Optional future usability evaluation

This is an unperformed procedure, not a study result. No participants, completion rates, hardware acceptance or impact claims are recorded.

Use an anonymous participant code, browser/version, OS and voluntarily supplied device class. Explain browser microphone processing, local webcam landmarks and optional server-side AI prompt/context processing before testing. Use non-sensitive example designs. Do not collect credentials, raw audio/video or unrelated personal logs.

Tasks: create/transform a cube; preview/cancel/confirm an AI house; target Part versus Structure; add a selected-wall window; insert standalone stairs; walk through door/stairs/balcony and reset/exit; save/load and exact Undo/Redo; stop camera; submit a finalized speech transcript if supported. Include keyboard-only and narrow-screen use.

For each task record completion, assistance needed, mistakes/cancellations, observed time and participant comments. Separately record displayed render FPS, camera presentation FPS, inference Hz/ms and engine for the same scene/light conditions; do not conflate sensor FPS or physical hand latency with software counters. AI latency/output is variable, so keep its timing separate. Leave unsupported-device tasks marked unsupported or pending. Report sample limitations and consent/collection choices before making any usability claim.
